# Dependencies

## `JBlots.java` / `j_blots.jar`

Requires the **ImageJ** plugin API (`ij.*` packages) to build and run
as an ImageJ plugin. ImageJ itself is not included in this repository
-- install it from https://imagej.net/ to build or run the plugin.

## `WesternBlotSegmentationAnalysis.cs`

Requires **Unity** and **OpenCV for Unity**, a third-party Unity Asset
Store plugin that requires a separate paid license from Enox Software.
Neither Unity nor OpenCV for Unity is bundled in this repository.
